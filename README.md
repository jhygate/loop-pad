# Loop Pad

A browser-based loop pad built with TypeScript.

## Prerequisites

- [Node.js](https://nodejs.org/) (v18+)
- npm (comes with Node)

## Setup

```bash
npm install
```

## Running the Project

| Command | What it does |
|---|---|
| `npm run dev` | Compile + serve simultaneously (recommended) |
| `npm run watch` | TypeScript watch mode only |
| `npm run serve` | Serve the app only |
| `npm run build` | One-off TypeScript compile |

For development, just run:

```bash
npm run dev
```

Then open `http://localhost:8009` in your browser.

## Project Structure

```
src/
  script.ts               # Entry point
  recorder/
    recorder.ts           # Recorder class (orchestrator)
    recorder-state-machine.ts  # FSM — pure state logic
    recorder-view.ts      # UI rendering
    recorder-settings.ts  # Per-pad settings
    recorder-constants.ts # Timing constants
dist/                     # Compiled output (generated by tsc)
index.html                # App entry point
```

## Deployment

The project deploys automatically to `jhygate.github.io/looppad` via the GitHub Actions workflow in `.github/workflows/deploy-to-jhygate.yml` when pushing to `main`.
